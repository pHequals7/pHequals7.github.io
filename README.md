# pHequals7.github.io

Legacy GitHub Pages compatibility host for Muesli Sparkle appcasts.

Older Muesli builds, including 0.6.8 and 0.6.9, have this feed URL embedded:

- https://pHequals7.github.io/muesli/appcast.xml

The canonical project now lives at Muesli-HQ/muesli, so this repo mirrors the org-hosted appcasts to keep older installed apps updateable.
